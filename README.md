# Feast & Fete 🍽️

Feast & Fete is a full-stack catering booking platform developed using Microservice Architecture.

## 🚀 Features

* Customer & Organizer Authentication
* Organizer Profile Management
* Catering Booking System
* Booking Request & Confirmation
* Protected Routes using JWT
* Responsive Modern UI
* Role-Based Access

## 🛠 Tech Stack

### Frontend

* React JS
* React Router DOM
* Tailwind CSS
* Axios

### Backend

* Spring Boot
* Spring Security
* JWT Authentication
* Spring Data JPA
* MySQL
* Microservices Architecture

## 📦 Microservices

* Authentication Service
* Profile Service
* Booking Service
* Payment Service

## 🔐 Authentication

JWT-based authentication and authorization implemented for secure access.
